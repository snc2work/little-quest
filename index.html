Little Quest

A tiny world model in your browser. It looks at the last frame and your key, and draws the next frame.
Walk into a hut or off the edge of the screen, and it makes up the place.
The model is small, so what it makes up is often a little broken, huts most of all.

# Key Model Real ms

How it works

  • The real game exists only to make training videos. The model never sees its rules, maps or rooms, only frames and keys. It runs here with ONNX Runtime Web, in a Web Worker.
  • A frame is an 8×8 grid of 4×4 blocks (60 kinds, collected from the training frames). The model picks a block for every cell over up to 8 rounds, surest first. Where the next frame is open, as in a new room or a new screen, it samples, so every world turns out different.
  • The model also says what happened (move, bump, enter, exit, cross…). From that alone the page keeps the last frame of each place. Going back to a place, that frame is handed to the model, which only draws the player again.
  • Huts on new screens often come out broken. A hut spans many blocks, and a model this small does not always make them fit together.
  • The black fade when going in or out is added by the page, not drawn by the model.
  • The same world number, keys and temperature give the same model world.
